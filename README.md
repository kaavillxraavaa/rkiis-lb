РКИС лаба1 бибилиоьека
Библиотека.
Программа запрашивает у пользователя имя и фамилию. Если пользователь есть в списке - то предлагает ему книгу(вызывает функцию по выбору книги). Если пользователя нет в списке - предлагает завести карточку(вызывается функция создания карточки и добавления в список) после чего предлагает взять книгу( вызов первой функции)
фото блок схемы и теоретический отчет также прикреплены
